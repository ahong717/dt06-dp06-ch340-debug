# 冷氣控制器使用者操作教學

## 1. 產品用途

本控制器使用 ESP8285 與 Midea/Sanlux 相容 UART 通訊協定控制冷氣，提供：

- Home Assistant 的 ESPHome 裝置與實體。
- 電腦及手機均可使用的本機控制網頁。
- 冷氣開關、模式、風量、溫度、擺風與室內機面板顯示。
- 模式選擇同時完成開機，模式列的「關閉」直接關機。
- 原廠機型支援時可控制 Midea 按鍵提示音（BEEP）。
- 關機防霉送風。
- 倒數開機與倒數關機。
- Firebase Hosting PWA、本機直連及 Firebase REST Streaming／SSE 遠端控制。
- Email／密碼註冊、裝置配對、解除綁定與移轉擁有者。
- 診斷日誌與網頁 OTA 更新。
- 無法連線時的 Wi-Fi 設定 AP。

控制器的基本冷氣通訊不依賴 Home Assistant或網際網路。區域網路暫時中斷時，冷氣通訊與已在控制器內開始的倒數流程仍可執行。

## 2. 第一次安裝

### 2.1 全新板子

1. 使用 `air-conditioner-final-factory.bin` 進行第一次 USB／UART 燒錄。
2. 將控制板接至相容冷氣，保持供電。
3. 開機後等待約 30 秒。
4. 手機的 Wi-Fi 清單會出現類似名稱：

   ```text
   air-conditioner-a1b2c3
   ```

   後六碼來自該控制板的 MAC 位址，每片板子不同。
5. 使用密碼 `12345678` 連線。
6. 若設定頁未自動出現，瀏覽器開啟：

   ```text
   http://192.168.4.1/
   ```

7. 選擇要使用的 2.4 GHz Wi-Fi，輸入正確密碼並儲存。
8. 裝置連線成功後，設定 AP 會自動關閉；到路由器的 DHCP 用戶端清單確認新 IP。

### 2.2 已安裝 ESPHome 韌體的裝置

使用裝置網頁的「韌體更新」上傳：

```text
air-conditioner-final-ota.bin
```

更新期間必須保持冷氣控制板供電。完成後裝置會重新啟動；已儲存在裝置內的 Wi-Fi 配網資料通常會保留。若執行 Factory Reset，必須重新配網。

## 3. 開啟控制網頁

將 `DEVICE-IP` 換成路由器分配給控制器的 IP：

| 網址 | 行為 |
|---|---|
| `http://DEVICE-IP/` | 英文介面，自動判斷桌面或手機排版 |
| `http://DEVICE-IP/?lang=zh` | 中文介面，自動判斷排版 |
| `http://DEVICE-IP/zh` | 轉向中文介面 |
| `http://DEVICE-IP/m` | 強制手機分頁排版 |
| `http://DEVICE-IP/m/zh` | 強制中文手機分頁排版 |

預設語言是英文。右上角按鈕可在中文與英文間切換。

手機版分為三頁：

- 主要控制：狀態、溫度、模式、風量；模式同時代表開關機。
- 進階設定：倒數計時、擺風、面板顯示、防霉。
- 系統：診斷日誌與網頁 OTA。

## 4. 即時狀態

頂部狀態區顯示：

- 連線／離線。
- 運轉中、已關機、等待防霉或防霉送風進行中。
- 目前冷氣模式。
- 目前設定溫度。
- 目前風量。
- 室內溫度。
- 室外溫度。

室外溫度若未回覆、超出合理範圍、等於已知異常值 102°C，或單次跳動超過 15°C，顯示 `N/A`，避免把通訊異常當成真實溫度。

## 5. 模式與開關機

### 5.1 開機與切換模式

首頁不設獨立開機按鈕。點選「自動運轉、冷氣、暖氣、除濕、送風」中的任一模式，冷氣會立即開機並進入該模式；運轉中再次選擇其他模式則直接切換。這與 Home Assistant Climate 手機介面的操作一致。

### 5.2 防霉關機

「防霉關機」依目前模式及「關機後自動防霉」開關判斷：

| 當下狀態 | 自動防霉 | 結果 |
|---|---:|---|
| 冷氣／除濕／自動運轉 | 啟用 | 立即切換送風 HIGH，完成設定時間後關機 |
| 冷氣／除濕／自動運轉 | 停用 | 直接關機 |
| 暖氣／送風 | 任意 | 直接關機 |
| 已關機 | 任意 | 不啟動送風 |
| 防霉等待或運轉中 | 任意 | 忽略重複的防霉關機要求 |

### 5.3 關閉

模式列的「關閉」立即：

- 停止防霉等待。
- 停止防霉送風。
- 將冷氣設為 OFF。

關閉命令本身不把冷氣設定改成送風、中等或 26°C。下次使用者直接選擇所需模式即可重新開機。

## 6. 運轉模式

可選模式：

| 顯示 | ESPHome 模式 |
|---|---|
| 自動運轉 | `HEAT_COOL` |
| 冷氣 | `COOL` |
| 除濕 | `DRY` |
| 送風 | `FAN_ONLY` |
| 暖氣 | `HEAT` |
| 關閉 | `OFF` |

點擊任何運轉模式都立即開機或切換模式；點擊「關閉」立即關機。沒有額外的開機／關機按鈕，也沒有模式待選步驟。

## 7. 風量

可選風量依序為：

```text
自動 → 寂靜 → 弱風 → 中等 → 強風 → 強力
```

冷氣運轉中點擊即時套用。冷氣關閉時風量控制停用；先選擇運轉模式開機後再調整。

## 8. 溫度

- 可調範圍：16–30°C。
- 調整步距：1°C。
- 拉動滑桿時只更新畫面；放開滑桿後才送出設定。
- 冷氣運轉中立即套用。
- 冷氣關閉時溫度控制停用；先選擇運轉模式開機後再調整。
- 送風模式不使用目標溫度。

## 9. 擺風與面板顯示

- 上／下：切換垂直擺風。
- 左／右：切換水平擺風。
- 兩者均開啟時，冷氣使用 BOTH。
- 面板顯示：切換室內機顯示面板。

部分冷氣協定只提供「面板切換」命令，無法可靠讀回真正燈光狀態；網頁顯示的是控制器維護的狀態。若實機與畫面不同，按一次面板顯示即可重新同步操作意圖。

## 10. 防霉送風

### 10.1 參數

- 防霉送風時間：15–90 分鐘，預設 30 分鐘。
- 關機後啟動延遲：1–10 秒，預設 3 秒。
- 兩個設定會保存至裝置 Flash。

### 10.2 自動防霉

「關機後自動防霉」為狀態開關：

- 啟用：冷氣由冷氣、除濕或自動運轉轉為 OFF 時，先等待設定秒數；若期間仍保持 OFF，切換為送風 HIGH；時間到後 OFF。
- 停用：一般關機不會自動啟動防霉流程。
- 暖氣與送風結束不觸發自動防霉。
- 等待期間若使用者重新開機，等待取消。
- 防霉送風期間若使用者改成其他模式，防霉倒數取消。

### 10.3 立即執行防霉送風

「執行防霉送風」可在冷氣、除濕、自動運轉或送風狀態啟動：

1. 立即切換為送風。
2. 風量固定為 HIGH。
3. 顯示剩餘時間。
4. 時間到後關機。

已關機或暖氣模式不能使用此按鈕。

### 10.4 停止防霉

「停止防霉」會停止等待或倒數；若正在送風，冷氣同時關機。

## 11. 倒數開關機

### 11.1 設定時間

- 範圍：0–999 分鐘。
- 短按 `+1`／`-1`：每次一分鐘。
- 按住約 200 ms：連續調整。
- 按住約 800 ms：每次十分鐘。
- 按住約 1300 ms：每次一百分鐘。
- 必須大於 0 才能建立排程。

### 11.2 倒數開機

只允許在冷氣目前為 OFF 時建立。

若沒有選擇參數，採用：

| 項目 | 預設 |
|---|---|
| 模式 | 送風 |
| 風量 | 中等 |
| 溫度 | 室內溫度四捨五入並限制在 16–30°C；室溫無效時使用 27°C |

送風模式忽略溫度。排程建立後，時間、模式、風量與溫度輸入立即清空，避免下一次誤用；狀態區會持續顯示剩餘時間與預計動作。

### 11.3 倒數關機

只允許在冷氣運轉中建立。時間到後直接 OFF，不進行防霉判斷。

### 11.4 取消與提早達成

- 按「取消」會刪除排程並清空輸入。
- 倒數開機期間若冷氣已被其他方式開啟，排程自動結束。
- 倒數關機期間若冷氣已被其他方式關閉，排程自動結束。
- 同一時間只允許一個倒數排程。

## 12. 診斷日誌

可選：

- Errors Only
- Warnings & Errors
- General Information
- Detailed Debugging

日誌可暫停；暫停後不在網頁持續累積訊息。網頁最多保留最近 80 行，避免長時間佔用瀏覽器記憶體。

## 13. 網頁 OTA

1. 手機進入「系統」，桌面版則開啟右側診斷區。
2. 選擇 `air-conditioner-final-ota.bin`。
3. 按「安裝更新」。
4. 確認更新。
5. 保持裝置供電，等待重啟與重新連線。

不得使用 `air-conditioner-final-factory.bin` 進行網頁 OTA。

## 14. Home Assistant

將裝置加入 ESPHome 整合後，可使用：

- Climate 主實體。
- 按鍵提示音（Beeper）開關；僅在原廠 Midea 相容協定與機型支援時有效。
- 面板顯示開關。
- 自動防霉開關。
- 防霉時間與啟動延遲。
- 防霉啟動、停止、防霉關機與直接關機按鈕。
- 倒數時間、開機參數、建立／取消排程。
- 室內、室外與目標溫度。
- 防霉及倒數狀態與剩餘時間。
- Wi-Fi 訊號、IP、SSID、運作時間及 ESPHome 版本。

## 15. 故障排除

### 看不到裝置網頁

1. 確認手機與裝置位於可互通的網段。
2. 從路由器 DHCP 清單確認 IP。
3. 使用 `http://`，不是 `https://`。
4. 若 Wi-Fi 無法連線，等待 30 秒後尋找 `air-conditioner-xxxxxx` AP。

### AP 出現

這表示裝置暫時無法連接已儲存的 Wi-Fi。AP 出現後仍會繼續嘗試連回原 Wi-Fi；原 Wi-Fi 恢復後通常會自行恢復正常連線。

### 重新配網

連上裝置 AP，開啟 `http://192.168.4.1/`，輸入新的 Wi-Fi。若完全無法恢復，可執行 Factory Reset；此動作會清除儲存設定，需重新配網。

### 室外溫度顯示 N/A

表示目前數值未通過合理性檢查，不代表冷氣故障。待冷氣回傳穩定有效值後會自動恢復。

## 16. 手機 PWA 與本機管理頁

手機桌面的「我的冷氣」是精簡日常 PWA。人在家且瀏覽器允許區域網路存取時，右上角會顯示「本機直連」；不在家、瀏覽器不支援或拒絕授權時，會顯示「雲端連線」。兩種模式的畫面與操作位置相同。

需要 OTA、Wi-Fi、Firebase、擁有者 Email、解除綁定或診斷 LOG 時，請主動用瀏覽器開啟 DT-06 的 `http://IP/` 或 `http://主機名稱.local/`，進入完整本機管理頁。PWA 不會因回到家而自動跳進工程頁。

PWA 只在前景且本機可達時每秒讀取一次本機狀態；Firebase 只在狀態改變時推送，無人觀看且狀態不變時每 15 分鐘回報一次存活狀態。本機直連使用裝置自動產生的專屬權杖，使用者不需輸入或記住另一組密碼。
