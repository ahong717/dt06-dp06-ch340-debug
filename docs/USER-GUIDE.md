# 一般使用者指南 (User Guide)

本指南說明如何使用已驗證的桌面 EXE 連接 DT-06 與 CH340。一般使用者不需要安裝 Python 或 Git。

## 1. 啟動程式

從 GitHub Releases 下載指定版本的 EXE，或使用專案根目錄的 `DT06_三洋冷氣模擬器.exe`。雙擊檔案即可啟動。

## 2. 連接 CH340

1. 將 DT-06 TX 接 CH340 RX、DT-06 RX 接 CH340 TX、GND 接 GND。
2. 確認電壓電平相容；ESP32 RX 不可直接承受 5V。
3. 第一次使用時，若 Windows 沒有顯示 USB-SERIAL CH340/CH341，先安裝對應驅動。
4. 在「裝置管理員 → 連接埠 (COM 和 LPT)」確認 COM 編號。
5. 在程式按「重新掃描」、選擇 COM 埠，再按「連線」。

通訊格式為 9600 8N1。同一時間只能有一個程式開啟同一個 COM 埠。

## 3. 使用冷氣模擬器

程式會模擬冷氣室內機，接收 DT-06 UART 控制並回傳狀態封包。畫面可觀察電源、模式、溫度、風量、擺風、定時與 UART 日誌。

右側遙控器按鈕會直接改變電腦內的虛擬冷氣狀態；它不是紅外線發射器，也不會代替真實遙控器向冷氣發射訊號。

防霉循環測試會依序執行冷房、遙控關機、等待 DT-06 防霉關機，再進入下一輪。測試期間請依畫面狀態判斷是否完成，不要把它當成真實冷氣的紅外線測試。

## 4. 常見問題

- **找不到 COM：** 檢查驅動、USB 線、TX/RX 是否交叉連接。
- **無法連線：** 關閉其他序列埠工具，確認沒有另一個模擬器占用同一個 COM。
- **Windows SmartScreen 警告：** 確認檔案來自可信的 GitHub Release 後，按「其他資訊」→「仍要執行」。
