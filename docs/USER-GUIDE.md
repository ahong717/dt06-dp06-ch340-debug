# 一般使用者指南

## 啟動

雙擊根目錄 `DT06_三洋冷氣模擬器.exe`，不需要 Python。

## CH340

第一次使用的電腦若沒有出現 USB-SERIAL CH340/CH341，請到 WCH 官方網站安裝 CH340/CH341 Windows 驅動。
裝置管理員的「連接埠 (COM 和 LPT)」會顯示 COM 編號；在程式按「重新掃描」、選擇它，再按「連線」。
通訊格式為 9600 8N1。只有一個程式能同時開啟同一個 COM 埠。

## 右側模擬器

右側按鈕直接改變電腦內的虛擬冷氣狀態，不是紅外線發射器。防霉測試流程是：遙控開冷房、運轉倒數、
遙控關機、等待 DT-06 經 UART 發出防霉完成的關機控制，確認後才進入下一輪。

## SmartScreen
