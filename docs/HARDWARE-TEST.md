# DT-06 / CH340 硬體驗證指南

本文件用於驗證候選 EXE 與實際 DT-06 韌體之間的 UART 互動。它不能取代真實冷氣上的最終驗證。

## 1. 驗證前準備

- DT-06 已燒入要測試的 FINAL 韌體
- CH340 與相容的 UART 線材
- 候選 EXE（通常位於 `build-output`）
- 沒有其他序列埠工具正在使用同一個 COM 埠

## 2. 接線與安全

- DT-06 TX → CH340 RX
- DT-06 RX → CH340 TX
- DT-06 GND → CH340 GND
- 確認電壓電平相容；不可把 5V 直接接到只容許 3.3V 的 ESP32 RX

## 3. 操作步驟

1. 開啟 EXE，按「重新掃描」。
2. 選擇 CH340 的 COM 編號並按「連線」。
3. 確認 UART RX/TX 計數與日誌開始更新。
4. 用右側遙控器依序測試電源、模式、溫度、風量與擺風。
5. 開啟防霉循環測試，確認每一輪都等到 DT-06 的防霉關機控制後才進入下一輪。
6. 記錄測試日期、韌體版本、EXE 版本、COM 編號與結果。

## 4. 驗收項目

- 程式可連線且不會自行斷線
- DT-06 控制封包能被模擬器正確解析
- 模擬器會回傳對應狀態封包
- 電源、模式、溫度、風量、擺風顯示正確
- 防霉循環不會在未收到 DT-06 關機控制前誤計數
- 異常封包或斷線時，畫面能顯示錯誤而不是假裝成功

沒有硬體時，可以執行自動測試驗證協議與狀態機；但自動測試通過不等於已完成實機驗證。
